# HTML 视觉优化 Issue 草稿

当前 v4 已将批准内容与视觉计划分离，但正文、封面和收尾仍共享相近的排版，主题间的字体重量与构图差异较小。图片缺少独立主视觉版式，QA 尚未直接测量标题行尾、标题与正文间距、图片主体裁切和导航安全区。

本轮在现有 HTML 模块中落实纸面杂志与瑞士风的字体、网格、图片槽位和整套节奏，沿用 1280×720 等比舞台。旧版内容继续走原渲染路径，确认内容及其修订由共享核心维护。

验收采用同一份明确标为样例的 8 页内容，保存两种风格的前后截图、浏览器动作、trace、QA 和产物绑定；随后单独维护现有 verify-storyweave 功能地图与 harness，驱动全部功能。未调用真实图片服务的路径按实际覆盖记录。
