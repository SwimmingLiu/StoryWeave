# 扩充技术分享参考图库

## 问题

现有 8 组主题共 9 张内容页，视觉选择有限。单张样图无法展示一种风格如何承载观点、流程、对比和数据，也不方便按实际页型检索。

## 方案

继续筛选有真实横向内容页的生图演示来源。优先增加技术分享可用的视觉语言，并为已有风格补充不同内容页。每张图片分别记录来源、职责、可观察内容、视觉查验和原生 HTML 的分工。来源只提供单页时保留覆盖缺口，不把一张图重复计算为多张。

用逐页记录替换并行的图片、尺寸和标签数组。画廊按风格、分享场景和观点、流程、对比、数据页筛选，并展示覆盖和缺口。第三方原图继续从来源加载，生成器、核心和现有主题规则不变。

## 验收

1. 风格数量明显多于现有 8 组，新增项有实际内容页和视觉差异。
2. 同风格尽量包含多张不同内容页，逐页标明已观察的职责与覆盖缺口。
3. 普通卡片、代码、表格和统计图不因来自生图工具就自动收录。
4. 分类、页型、搜索和空状态使用同一份权威目录；生成资源可重建并检查。
5. 全局增量同步可恢复，原有脚本和主题哈希不变，四包保持独立。

## 检查记录

图库由 8 种风格、9 张图片扩到 18 种风格、41 张内容页。17 种为多页参考，黑板粉笔保留单页并显示缺口。水墨黑板和协作白板的四类职责齐全；其余组按来源实际情况记录待补项。

逐页标签与筛选脚本已完成静态数据检查和六项筛选逻辑检查。本地画廊浏览器导航此前受到工具安全策略限制，本次不通过替代导航绕过；单张远程原图已在浏览器查看。运行包、全局资源与独立分发检查结果保存于 `tmp/presentation-expansion/verification.json`。
