# 扩充技术分享的多页参考，并按实际页型筛选

原参考库只有 8 种风格、9 张图片，单页样张无法展示同一视觉方向如何承载不同内容。参考库现有 18 种风格、41 张实际内容页，17 种包含多页，技术分享风格优先显示。

新增黑金运行叙事、角色引导技术讲解、协作白板、银白玻璃技术叙事、复古立体开发者、用户旅程分镜、漫画工程叙事、场景式平面图解、柔和彩绘与像素流程。纯 HTML 卡片、标准流程图、普通仪表盘和独立实体插画继续排除。

每张图片分别记录观点、流程、对比、数据或架构职责，附来源、提示词范围、视觉查验与 HTML 分工。画廊组合场景、页型与搜索条件，自动展开实际匹配的内容页。覆盖统计从图片生成，同一图片不会重复增加总数。

水墨黑板与协作白板覆盖四类内容，其他风格显示实际缺口；黑板粉笔保留单页状态。来源中的同风格集合、同一套演讲和多个来源的视觉方法分别说明，不将跨来源样张当作已验证的整套连续性。

验证包括目录生成一致性、六项筛选逻辑、独立安装和全局资源核对，现有 121 项回归全部通过。全局 CLI、主题和工作流保持原文件哈希。原图仍由来源加载，参考更新不引入新的服务或运行依赖。

本地画廊的浏览器导航受到工具安全策略限制，浏览器渲染未验收。逐张远程原图已查看，静态检查和筛选逻辑检查分别记录范围。
