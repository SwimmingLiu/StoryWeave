# HTML 视觉复核修订 Issue 草稿

上一轮样张在内容与几何检查通过后，人工复核仍发现正文孤字、流程箭头贴近编号、中性对照的单列高亮，以及图片与论点联系偏弱。杂志与瑞士风的系统图和图片页也缺少足够的构图差异。

本轮保持两套批准稿的全部字节与修订不变，将中文短词保护扩展至正文和图解，按实际节点边界生成连线，使用中性比较样式，并重新组织图文与系统图。图片素材使用无新增文字或数据的版式示意图，直接表现已批准的阅读顺序、密度与留白主题。

QA 应识别正文孤字、被拆开的短词、连线与文字或编号冲突，以及中性对照的非对称强调。验证保留修改前版本、两套新 8 页样张、双视口截图、动作、trace 和逐页前后对照，再进行人工逐页复核。
