# 视觉语义生成方案

来源为 Damir Sokolovsky 的视觉版 [unslop](https://github.com/heydamir/unslop/tree/1d13095e4bef6ad6c74f1dd828d84c4ba309a4dc)，按 CC BY 4.0 保留署名。采用内容决定方向、局部问题局部修整、素材证明主张、安静的辅助元素和实际截图比较。保留演示文稿的主题媒介、批准文案与 16:9 舞台，不机械移植网页尺寸、标点或字重规则。

共享模块从批准内容生成可检查的视觉意图，区分观点、比较、指标、流程与关系图。它不猜测行业隐喻，不编造具体物体，也不生成“视觉审核通过”标记。两种生成器把版本与意图纳入计划和指纹；Imagegen 将对应要求编入真实任务提示词，不能只在文档中说明。

HTML 的有向无环关系图在宽舞台沿层级从左到右展开；只有批准边本身形成循环时使用循环结构。主题继续通过字体、色彩和节点处理形成差异，不用额外方向变化制造新意。

三个分发 Skill 都带可独立读取的生成前检查说明。制作时先写内容、受众、媒介、视觉焦点和需保留的特征；更新时先列实际问题和最小修改。生成后继续使用已建立的逐页视觉比较，退步或不确定不放行。
