# Imagegen QA 与导出

## 自动检查

检查批准内容、计划修订、任务指纹、页序、ID、参考哈希和实际调用记录。图片必须存在且可识别，比例符合 16:9 要求。默认请求 `2048x1152`，工具返回其他尺寸时记录实际值与 warning，不把请求尺寸写成实际尺寸。

`text_policy` 为 `exact-text-in-image`，每页 Review 必须通过并绑定实际 PNG 哈希。`record-result` 只收集结果，仍需执行逐页复核。旧 QA 和旧复核不能批准替换后的图片。

`qa_report.json` 的 `artifact_binding` 绑定当前批准内容、计划、参考、实际调用记录、清单与页面。导出和 Bento 交接再次核对实际文件。

## 逐页视觉复核

| 内容 | 检查 |
| --- | --- |
| 所有页面 | 只出现确认文字，没有乱码、额外标签、水印或错误裁切 |
| 流程与关系 | 顺序、方向、节点与确认内容一致 |
| 指标与比较 | 数字、单位、比较维度与来源正确 |
| 图片主视觉 | 主体、文字区、层级和对比度清楚 |
| 全套页面 | 风格、视觉锚点、密度与转场一致 |

当前没有 OCR。`review --pass` 是对已查看图像的记录，不能代替视觉判断，也不证明自动识别过文字。发现问题标记 revise，只重生成受影响页面。

## 导出边界

| 格式 | 结果 |
| --- | --- |
| PNG | 原始整页图片 |
| HTML | 以图片为内容源的离线画廊 |
| PDF | 整页图片打印输出 |
| PPTX | 每页一张图片，保留备注 |

修改源是草稿、批准内容、私有计划、任务和图片，不是 PPTX 内的文字或图形对象。缺少导出依赖时保留 PNG 和报告，未实际执行的格式单独记录。
