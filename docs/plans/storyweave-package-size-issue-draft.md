# 减少独立 Skill 的重复运行文件

## 背景与问题

四个 Skill 已能独立运行，但当前打包器按目录复制模块，Express 与全局包带入了内容审批和主题合同等未使用模块。两个 Bento 包还各自保存 677,480 字节的相同官方 HTML。

上轮体积统计排除了示例、文档和依赖，只代表部分运行文件。Imagegen 的主题示例图片占据主要安装空间，缩减 Bento 和 core 后需要同时报告运行文件与完整安装目录的变化。

## 解决范围

从各公开 CLI 入口确定所需模块，原始代码仍由 `src/` 唯一维护。官方 Bento 原稿保留一份，独立包携带可逐字节恢复的运行资源。打包校验、安装备份、离线包装、缓存与在线更新继续使用各自清晰的文件身份。

Imagegen 主题另核对仓库与全局安装版的目录、方案和预览状态，记录两处差异。

## 验收条件

- 四个 Skill 分别安装到不同根目录，在仓库之外完成对应公开入口；全局包旁边没有 Express。
- 所需源码、合同和运行资源均在本包内，安装后不访问相邻 Skill 或共享运行时缓存。
- Bento 资源恢复后的 SHA-256 与官方原稿一致，损坏资源拒绝使用；直接包装与全局包装均通过浏览器检查。
- 以当前八页固定语料对比优化前后 HTML、桌面与移动截图，内容和画面保持一致。
- 包体积以实际文件字节计数，报告必需运行文件和完整安装目录两种口径，包含草稿所需的内容模板。
- 完整回归、打包一致性与验证证据均对应最终源码，清理后证据仍可读取。
