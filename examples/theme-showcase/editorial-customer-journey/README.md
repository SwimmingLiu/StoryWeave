# 编辑叙事：客服体验

这个案例用 `editorial/paper-magazine` 讲述客服体验如何从一次回答延伸为连续关系。页面依次建立服务现场、拆解服务判断，再用一条低密度结论收束。

| 页面 | 视觉方案 | 页面主张 |
|---|---|---|
| s01 | `magazine-cover` | 客服体验从一次回答变成一段可连续的关系 |
| s02 | `editorial-diagram` | 把一次咨询拆成可复用的服务判断 |
| s03 | `editorial-statement` | 好的客服不是更快结束，而是让用户少走一步 |
