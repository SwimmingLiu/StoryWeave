# HTML 模板参考

这里保存 Beautiful HTML Templates 的 34 组模板索引。每组均链接到固定提交中的 `template.html`，截图是 HTML 页面预览。`curation.json` 中的 `render_route` 为 `html`，`imagegen_reference_eligible` 为 `false`。

| 类别 | 组数 | HTML 实现方式 |
| --- | --- | --- |
| 极简留白 | 2 | 字阶、边距、细线与网格 |
| 编辑排版 | 8 | 多栏、衬线字体、色带与裁切 |
| 手绘便签 | 3 | 卡片、旋转、边框、阴影和 SVG 装饰 |
| 网格粗框 | 3 | CSS Grid、粗边框与几何色块 |
| 复古数字 | 4 | 窗口组件、像素图标、网格与彩条 |
| 自然质感 | 3 | 配色、字体、背景材质与图片素材 |
| 商务研究 | 3 | 表格、数字、原生图表与分区 |
| 海报表达 | 5 | 展示字体、单一主张与大色块 |
| 趣味几何 | 3 | 圆角、图形、位置与颜色组合 |

复杂插画或照片可以作为 HTML 页面中的独立素材。页面使用图片素材，不等于需要将整页栅格化。

`upstream.json` 保存来源提交、源文件链接、图片路径和哈希。`LICENSE.txt` 保存上游 MIT 文本。外部字体和素材仍按各自来源取用。
