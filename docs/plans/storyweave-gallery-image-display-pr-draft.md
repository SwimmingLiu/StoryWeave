# 为参考图库提供离线图片与明确的加载状态

参考图库依赖外站图片，缺少图片加载失败提示。批量读取实际原图时，三张出现连接中断或超时；重试后 41 张全部可读取。远程地址有效不能保证本地页面稳定显示。

每组首图现在直接请求，折叠内容页展开后立即请求。加载失败时显示重试与原图链接，加载成功后可以打开大图。没有 JavaScript 时，加载占位层不遮住原始图片。

新增独立离线导出。缓存保持原图字节并核对格式、尺寸和哈希，导出 HTML 内嵌全部图片；缺少缓存或哈希变化时拒绝输出。离线产物放在项目查看目录，四个 Skill 的分发包只保留小型索引与页面。

验证包括 41 张原图完整解码、内嵌字节与缓存哈希一致、六项加载状态与筛选脚本检查、独立安装和全局资源核对。现有 121 项回归通过，既有主题、CLI 与工作流文件保持原哈希。

浏览器工具禁止访问本地文件，实际浏览器渲染仍未验收。图片解码、内嵌完整性与脚本状态检查分别记录，没有以静态检查代替视觉验收。
