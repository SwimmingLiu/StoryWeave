# HTML 视觉回归的 CI 方案

每次 CI 从公开八页示例创建杂志、瑞士风两套项目，通过公开 CLI 完成批准、视觉重规划、构建和浏览器 QA。示例审批仅用于固定测试内容。布局示意素材解释空间分配，不加入事实；重规划前后逐字节核对批准稿。

固定基线保存 Linux CI 实际截图、内容修订、主题、渲染环境及署名视觉观察。评审覆盖 16 页的主张、阅读、关系、构图和素材语义，以及两套的连贯性、节奏。任何维度失败或不确定均不能接纳为基线。

CI 将当前截图与已评审基线逐字节比较，相同画面继承已有判断；任一截图、内容或环境变化均为 needs-review，并使必需的 Verification 失败。它不从像素分数推导审美，不自动更新基线。失败仍保存两套 HTML、桌面与竖屏截图、逐页对照和空评审模板。

第一次运行先产出待评截图，由代理实际逐张查看、填写观察，再通过显式 accept 命令绑定到这些截图并提交。后续修改沿用相同过程。CI 不调用付费生图或依赖额外模型密钥。
