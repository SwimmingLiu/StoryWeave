# Imagegen 工作流

```mermaid
flowchart TD
  A[用户需求与资料] --> B[检查页数、事实与缺口]
  B --> C[中心含义与五段叙事]
  C --> D[逐页主张、准确文字、视觉构思]
  D --> E{用户确认 Storyboard}
  E -->|修改| C
  E -->|确认| F[选择一个图片主题]
  F --> G[冻结逐页文字与视觉锚点]
  G --> H[编译完整页面提示词]
  H --> I[逐页调用 imagegen]
  I --> J[尺寸、文字、构图与主题检查]
  J -->|未通过| K[只调整一个问题并重生成该页]
  K --> I
  J -->|通过| L[标记 review=pass]
  L --> M[生成离线画廊与导出]
```

Storyboard 是生成门。每页只保留一个主张，`exact_text` 明确列出图片中允许出现的全部文字，`layout_plan` 冻结文字安全区、视觉区、层级和密度。用户未确认前不生成图片；资料缺失时缩短页数或标记 `unresolved`。

图像生成后先检查机器可验证的尺寸、比例和文件完整性，再做逐页视觉复核。复核问题按“文字准确性 → 文字可读性 → 主体与裁切 → 主题一致性 → 页面节奏”顺序处理，每次只改变一个变量。
