# 编辑叙事：客服体验视觉方案覆盖

这组 coverage deck 使用 `editorial/paper-magazine` 验证基础 showcase 之外的四种页面表达：纪录主视觉、人物特写、对照跨页和编辑拼贴。内容仍围绕客服体验中的上下文连续性展开。

| 页面 | 视觉方案 | 页面主张 |
|---|---|---|
| s01 | `documentary-hero` | 一条问题从窗口进入，也带着上下文留下 |
| s02 | `profile-feature` | 接住用户的人，不该从一句自我介绍开始 |
| s03 | `comparison-spread` | 同一件事，不要让用户重复讲两遍 |
| s04 | `collage-scene` | 让下一次服务接着上一次发生 |
