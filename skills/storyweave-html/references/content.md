# 内容、来源与页面角色

## 简洁性

- 每页只有一个可复述的主张，标题本身应能组成完整叙事链。
- `speaker-led` 页面可见正文以 60 个中英文字符为提醒线，不是机械截断线；超出时优先拆页或移入讲者备注。
- 不写“本页将介绍”“如图所示”等说明性废话。
- 数据、引语和判断分别标清证据；不把商业假设写成事实。
- 用户提供的非公开材料才可进入事实性页面；公开数据记录来源 URL、检索日期、口径和单位。
- `provided`、`inferred` 和 `placeholder` 分开记录。没有证据的数字、引用、人物和结果只能作为待补项，不能直接上页。

## 角色使用

| 角色 | 适用内容 | 必查项 |
|---|---|---|
| cover | 标题和语境 | 主题明确、无信息堆积 |
| section | 章节转场 | 下一段叙事目的明确 |
| statement | 单一结论 | 主张足够具体 |
| image-hero | 产品、场景、对象 | 图片主体、来源、裁切 |
| two-column | 两组并列信息 | 两侧层级一致 |
| comparison | 前后或方案对比 | 比较维度一致 |
| process | 步骤、责任、分支 | 顺序和术语一致 |
| data | 指标和趋势 | 口径、单位、时间、来源 |
| quote | 引语或证言 | 原文、人物、出处 |
| closing | 总结与行动 | 明确下一步 |

页面角色是内容语义，不是固定模板。布局切换只能在角色兼容范围内进行。`exact_text` 是页面可见文字的封闭列表；HTML 必须逐字渲染，不增加模型自造标签或说明。
