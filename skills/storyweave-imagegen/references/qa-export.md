# QA 与导出

## 机器检查

- Storyboard 页数、顺序和 manifest 一致。
- 每页图片存在、可识别、比例为 16:9；默认尺寸为 `2048x1152`。
- `text_policy` 必须是 `exact-text-in-image`；所有页面必须显式标记 `visual_review: pass` 才能导出。
- 输出 HTML 只能引用项目内的图片路径；PPTX/PDF 页数必须与 manifest 一致。

## 逐页视觉检查

| 页面角色 | 必查内容 |
|---|---|
| 封面 / 章节 | 中心主张、标题层级、主题锚点和第一眼焦点 |
| 流程 | 顺序和方向是否直观，文字是否完整 |
| 数据 / 比较 | 数字、单位、比较维度和来源是否只来自确认材料 |
| 图片主视觉 | 主体裁切、文字区清晰度、额外文字和水印 |
| 结尾 | 行动是否明确，页面是否留有呼吸空间 |

Imagegen 不能用 OCR 或脚本保证中文无误，因此必须由模型或用户查看实际图片。发现乱码、文字与背景冲突或主题漂移时，标记 `revise` 并只重生成该页。

## 导出边界

| 格式 | 说明 |
|---|---|
| PNG | Imagegen 原始整页图片 |
| HTML | 离线翻页画廊，图片是唯一内容源 |
| PDF | 浏览器打印出的整页图片 |
| PPTX | 每页一张整页图片，保留 notes；对象级不可编辑 |

源文件和可修改对象不是 PPTX，而是 `outline_draft.json`、`deck_spec.json`、`imagegen-jobs.jsonl` 和 manifest。修改应回到草稿或重新生成指定页。
