# 在生成阶段预防视觉 AI slop

现有视觉语义评测可以拒绝退步，但两个生产 Skill 还没有共同的生成前约束。Imagegen 任务依赖主题的构图和素材提示，缺少对本页信息形态的明确要求；HTML 曾为了主题差异，把清楚的横向分流汇合改为被用户拒绝的纵向结构。

本次将视觉版 unslop 的方法接入全局编排、HTML 与 Imagegen 的制作入口，并在实际计划与图片提示词中保留内容驱动的视觉意图。信息的方向、比较轴和事实优先于装饰与主题差异。已有批准内容和旧产物保持只读。

验收应证明两种主题不会仅因名称不同改变关系图方向，图片任务明确说明每种内容如何表达、装饰需要什么依据，旧策略计划需要重规划。编译与测试通过只证明约束已经接入，实际无 slop 仍需逐页看图。
