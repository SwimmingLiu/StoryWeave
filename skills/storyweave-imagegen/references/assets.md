# 图片资产约束

- 图片按 `slides/<slide-id>.png` 保存，manifest 同时记录模型、尺寸、质量、prompt hash、尝试次数和复核状态。
- 默认目标为 `2048x1152`（16:9），实际输出以当前工具支持为准，并在 QA 中记录真实像素尺寸和比例。用户明确要求精确尺寸时，验证该要求；不能把近似比例或上采样结果写成原生精确输出。
- 用户提供的图片保留来源和用途；公开素材记录 URL、作者、许可证和检索日期；非公开素材必须由用户提供。
- 生成图只能表达概念、氛围或已确认文字，不能冒充真实产品截图、数据证据、人物照片或引用来源。
- 失败变体留在项目外部缓存或被清理，不把失败图嵌入最终画廊。不要使用占位图伪装完成。
