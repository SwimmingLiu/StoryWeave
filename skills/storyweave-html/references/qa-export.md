# HTML QA 与导出

## 自动检查

结构检查核对公共 manifest、稳定 ID、相对资源路径、批准内容、计划修订与规则哈希。schema 4 的可见文字必须与结构化投影一致，流程和关系图的边必须对应确认关系。

浏览器检查在 `1280×720` 与 `390×844` 运行，覆盖独立页面和画廊中每一页。检查舞台、字号、标题行数、资源、越界、意外重叠、关系与额外可见文字。竖屏使用整体缩放，页面内容不临时重排。图注来自批准内容，参考资源变化会阻断检查。

浏览器不可用时记录 degraded。最终交付要求 `visual_review: browser`，blocking 与 degraded 为零；warning 逐项解释。

## 文件身份与视觉评审

`qa_report.json` 的 `artifact_binding` 记录清单、入口、页面、确认稿、私有计划及声明素材和参考的实际字节。检查前后核对文件未变化，导出与 Bento 交接再次验证。手工改动后的文件不能沿用旧 QA。

自动检查不判断审美。查看相同内容、相同主题的前后页面和整套缩略图，记录主张、关系、字阶、素材与节奏的具体判断。不要以 `export_ready` 代替这份视觉结论。

## 导出边界

| 格式 | 结果 |
| --- | --- |
| HTML | 原生页面与离线画廊 |
| PNG | 浏览器渲染图片 |
| PDF | 固定画布的逐页打印输出 |
| PPTX | 每页一张图片，保留备注 |

HTML 保留原生编辑能力。Bento 在生产者 QA 通过后另行包装和检查，报告位于 `qa/<output-id>.adapter-report.json`，不覆盖生产者报告。
