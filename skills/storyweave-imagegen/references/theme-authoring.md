# 主题维护方法

主题指令应补充模型不知道的视觉选择与工具契约。评估一条规则时，判断删除它会改变哪项决策或破坏哪项结果；无法说明作用的泛泛要求可以删去。

## 每层只负责一种决策

| 位置 | 保留的内容 | 下放或合并的内容 |
| --- | --- | --- |
| `SKILL.md` | 适用任务、交付物、授权条件、参考入口 | 主题全集、重复页面规则 |
| 架构 | 空间关系、阅读顺序、跨页节奏 | 字体、颜色和固定单页构图 |
| 样式 | 色彩、字体搭配、材质、可见锚点 | 单页标题尺寸、每种页面的布局 |
| 视觉方案 | 适合的角色、构图、媒介、标题处理 | 通用文字与事实约束 |
| 编译器 | `exact_text`、事实边界、冻结布局、所选锚点 | 全局禁拼贴、全局禁网格等审美偏好 |
| QA | 文件与实际画面是否符合约定 | 为改一句主题说明重建全部示例 |

把规则分成三类：格式与事实契约必须保持；审美偏好用默认值表达；特定故障的处理带上触发条件。例如“标题放在安静区域”是可读性要求，“标题始终巨大”是设计偏好，应交给单页方案。

## 修改顺序

1. 定位用户要改的主题、方案及其编译调用。比较 recipe 与实际 prompt，先修互相抵消的要求，再合并重复规则。
2. 保留使主题可辨认的色彩、材质和锚点；只传当前选定锚点的视觉描述，内部 ID 留在记录中。
3. 用正面构图描述替换宽泛禁令。确有用途的 `avoid` 留在对应样式或方案，并在编译时去重。证据只支撑事实，所有可见标签仍须进入 `exact_text`。
4. 保留 schema、完整引用、角色适配、安全区、状态与 hash 校验。需要突破这些限制时同步修改代码和验证，不能只在文档里宣布放宽。
5. 检查所改方案的编译结果及受影响测试。只有视觉效果仍不确定或用户要求看图时，才生成代表页；涉及标题、流程、数据等不同效果时，选择覆盖这些差异的少量页面。

已有候选主题保持 `candidate`，不能因脚本通过就升级为 `active`。机器检查只证明数据与编译有效；生图后的文字、构图和可读性仍需查看实际图片。修改 recipe 会改变 hash，旧项目应重新编译受影响内容，不能冒用旧图的通过状态。

从已选图片提炼新主题时，将它标为配方的设计参考，记录原始提示词、实际尺寸与图片哈希。参考图可以早于配方，不据此声称它由该配方编译生成或所有页型均已通过。已随 Skill 保存的图片可作为预览共用资产，路径须留在本包内，并在独立安装中核对实际字节。

## 验收情境

| 请求 | 预期行为 |
| --- | --- |
| 调整纸面主题的留白 | 修改相关 recipe，检查编译；无需询问整套页数 |
| 选择 `collage-scene` | 编译结果允许整页内部拼贴，同时保持文字契约 |
| 采用给定定稿直接生成 | 沿用授权定稿并继续，不重复索要同一确认 |
| 数据页引用资料中的数字 | 可见数字先进入 `exact_text`，不自动绘制证据里的额外标签 |
| 只改一个视觉方案 | 验证该方案和共享调用影响，不重生成全部样张 |

上述方法结合了 [GPT-6 Astra 指导](https://developers.openai.com/api/docs/guides/latest-model/gpt-6-astra) 关于指令敏感性、澄清和测试范围的建议，以及 [Skills 指导](https://developers.openai.com/codex/skills/) 的明确触发范围与渐进加载原则。它用于改进主题策划指令；不能据此推断图像模型与 Astra 具有相同行为。

## 用当前 Imagegen 验证主题

先为样式确定一种主要媒介、颜色职责和可辨认的主体处理，再让单页方案决定标题尺度及构图。用同一段短文比较不同样式，另选流程或数据页验证信息表达。样张中的主体只属于该页，不写成全主题的默认道具。

提示词沿用当前 `$imagegen` 的用途、主体、媒介、构图、逐字文字和约束组织方式，交给现有编译器生成。对照片明确自然光、物体表面和动作接触，对图表明确标签对应关系、基线和比例；不要通过增加技术形容词代替具体视觉决定。

局部编辑适合修复已经观察到的单项问题。先查看原图，标明它是编辑目标，写清要变动的部分与需保持的文字、布局、身份或光线；保存原始生成提示词、编辑提示词与来源，复核输出后再替换候选预览。修改 recipe 后重新计算 hash，不能把编辑后的图片记成未经编辑的原始输出。

内置工具仅传当前支持的参数。`2048x1152` 是期望目标，实际尺寸和模型选择按工具结果记录；不把 CLI 的 `quality`、`model` 或尺寸参数假装成内置工具字段。文字、精确断行、重复主体和数值几何都需要检查，提示词写明要求不代表结果已满足。生成图适合验证图表风格；需要精确数值比例的生产页面须核验几何，必要时使用有依据的图形参考重新生成。
