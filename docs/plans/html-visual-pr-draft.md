# PR 草稿：改进 HTML 杂志与瑞士风，并补齐真实验收

v4 页面原先共享相近的构图，图片页会把长中文标题挤成多行，主题预览中的相对图片路径也未随输出目录调整。本改动让视觉计划明确选择布局、字阶、网格、图片槽位和整套色调，renderer 生成对应的原生 HTML/CSS/SVG，QA 按固定舞台测量真实页面。

杂志风使用衬线标题、错列正文和纵向数字账单；瑞士风使用轻字重、16 列网格、对开论点与收尾。新增图片主视觉、短中文词组断行和主体裁切检查。参考改变版式后会重新计算图片槽位，带图预览按自身目录定位资源。旧 v2 文字容器留出与图片区的间距，v2/v3 内容与导航入口继续兼容。

验收 Skill 维护与产品修复分阶段完成。七个功能均经过只读源码核对和实际驱动；新 harness 覆盖两种视口的画廊操作、焦点空格、旧版内容、同内容前后对照、缺图门、参考应用和四包独立业务入口。

验证结果：120 项测试通过；两套 8 页样张在 1280×720 与 390×844 均为 browser、blocking/degraded 0；批准稿字节及修订不变。最终运行 `html-visual-20261101-a04` 为六项 pass、一项 needs-images，清理后 901 份文件哈希有效。Imagegen 仅实测编译与缺图门，真实生成、结果收集、OCR 和独立图片复核未执行。

本轮 HTML 运行包从 246,045 增至 264,307 bytes，增加 18,262 bytes，使用相同的文件内容计量口径；未增加运行时依赖。Imagegen 的同期体积变化来自并发工作，单独记录。源码、样张和本地草稿保留在工作区，未发布、推送或创建远端 PR。
