# 影像叙事：夜间交接

这个案例用 `cinematic/natural-film` 讲述夜间客服交接。页面先建立值班现场，再停留在人工接手请求的动作，最后用离场镜头收束到下一班继续服务。

| 页面 | 视觉方案 | 页面主张 |
|---|---|---|
| s01 | `film-opening` | 夜间值班，服务仍然继续 |
| s02 | `human-moment` | 当系统交给人工，交接不能从零开始 |
| s03 | `quiet-ending` | 让下一班人接住已经发生的事 |
