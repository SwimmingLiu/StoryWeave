# 减少独立 Skill 运行文件并保留 HTML 效果

四个 Skill 曾按源码目录打包，适配器因此带入未使用的内容和主题代码，两个 Bento 包还各保存一份原始 HTML。现在按 CLI 依赖复制原字节模块，官方 Bento 原稿集中维护，两包分别携带可校验恢复的 Brotli 资源。生成 JSON 同时去掉格式空白。

必需运行文件合计减少约 20.4%，从 1.89 MiB 降至 1.51 MiB。完整安装目录减少约 1.35%；Imagegen 的主题示例仍保留。计数包含草稿运行所需的内容模板，两种口径与原始字节表见[验证记录](storyweave-package-size-validation.md)。

116 项回归全部通过。四包分别安装在不同根目录并在 checkout 外运行，七类用户路径通过，清理后证据哈希一致。HTML 与 core 源码未改，九份 HTML 和十六张桌面、移动截图逐字节一致。Bento 恢复后的官方 SHA、损坏拒绝、缓存与在线更新兼容均有回归。

构建的依赖分析在专用子进程使用 Node `SourceTextModule`，运行时仍使用标准 ESM。新增动态导入需要明确处理，不能依靠目录复制掩盖遗漏。主题核对另记录了全局版六套与仓库四套的差异，本次未改主题或覆盖全局安装。
