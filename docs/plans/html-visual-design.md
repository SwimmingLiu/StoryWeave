# HTML 视觉实施方案

参考 [guizang-ppt-skill](https://github.com/op7418/guizang-ppt-skill/tree/c91369c449d34755d320a8b81d0734000d99d1ab) 的原始模板、布局说明、Swiss layout lock、checklist 与校验器。参考版本为 `c91369c449d34755d320a8b81d0734000d99d1ab`，许可为 AGPL-3.0。本轮独立编写 StoryWeave 规则与实现；参考代码、字体文件、背景和图片不进入运行包。模板浏览器截图留在本轮外置证据目录。

| 维度 | 纸面杂志 | 瑞士风 |
| --- | --- | --- |
| 现有主题入口 | editorial/paper-magazine | systems/ink-blue-grid |
| 字体 | 本地宋体标题、衬线数字、黑体正文 | 本地无衬线，巨字 300、正文 400、小字 500 |
| 构图 | 12 列、宽窄非对称、正文留白、纵向数字账单 | 16 列、共同左轴、对开论点、横向数字账单 |
| 节奏 | 深色封面、浅色内容、深色观点或数据、深色收尾 | 锚点色封面、浅色内容、深色数据、半屏色收尾 |
| 图片 | 横幅主视觉或 4:3 配图，图注在独立行 | 21:9 主视觉、直角、无阴影，主体安全区写入计划 |

以舞台设计值代替参考中的 vw/vh。页面内容停在 y=640 之前，底部 80px 留给页码和导航。标题字号按信息类型与长度分档；中文用浏览器均衡断行，QA 检查实际字符行框与孤字行尾。正文至少 24px，图注至少 16px。密集页先换布局或拆页，不改批准文字。

计划选择适合内容的布局、字体、图片槽位、色调与密度；renderer 生成实际 DOM/CSS/SVG；QA 测量真实浏览器几何。仅显式循环使用 loop；只渲染批准关系边。图片版式需要真实资产引用，不补造指标、标签或说明。

先保存工作区源码、包体积和优化前样张，再实施并重建同内容样张。产品代码完成并同步运行包后，进入验收 Skill 维护阶段；该阶段只修改 `.agents/skills/verify-storyweave/`。所有运行采用独立 ID，清理保留证据并复核哈希。
