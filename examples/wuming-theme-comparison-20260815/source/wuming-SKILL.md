# 青蓝电路发布会 PPT

把用户的新内容转成一张 16:9 横版 PPT 风格图片，并默认调用 `imagegen` skill / 内置 `image_gen` 工具生成图片。

## 效果预览

![效果预览](assets/preview.png)

预览图只用于展示目标视觉系统和审美方向。后续生成新图片时，复用色系、材质、信息层级和整体气质，不照搬预览图的细节结构、文案或装饰位置。

## 风格定位

这是一种白底青蓝电路和发布会科技感结合的演示页风格：清爽、精准、带一点仪式感。使用时保留青蓝细线、电路圆环、编号节点和高留白，不照搬预览图的圆环位置。

## 色系与视觉气质

- **背景**：白色或极浅蓝背景，高留白，光感干净。
- **主色**：青蓝、蓝绿和深蓝灰用于标题、线路、节点和主要强调。
- **强调色**：浅青、淡蓝、白色高光和少量渐变用于科技层次。
- **图形语言**：电路线、HUD 圆环、编号节点、细线连接、线性图标和轻量几何。
- **文字与密度**：标题清楚现代，模块简洁，整体像发布会或科技说明页。

## 内容处理原则

- 先理解用户内容，提炼成适合一页图讲清楚的主题、核心表达和自然分组。
- 根据内容选择页面形态，可以是封面、目录、流程、对比、矩阵、架构、数据概览或观点总结；不要为了贴合预览图强行套用某一种结构。
- 图中文字只保留短标题、短标签和少量说明；长文要改写成可读的结构化要点。
- 视觉元素服务于信息层级，不为了装饰而增加复杂图形。
- 系列图需要保持同一套色彩、字体气质、留白、图形语言和信息密度。

## Prompt 组织原则

组织 imagegen 提示词时，优先写清这些信息：

1. 图片类型与比例：16:9 横版 PPT 风格图片。
2. 用户主题和核心表达：说明这张图要讲清什么。
3. 自适应结构：描述内容关系，让版式随内容自然变化。
4. 色系与风格：写入本 skill 的背景、主色、强调色、材质和图形语言。
5. 文字要求：中文短标签，清晰可读，避免长段落和密集小字。
6. 负面约束：不要水印、Logo、真实品牌资产、乱码、复制参考图文案或让文字被遮挡。

## 出图规则

- 用户说“生成图片”“直接出图”“画一张”“配图”“PPT 图”“演示页”时，整理最终提示词并调用 `image_gen`。
- 用户明确说“只给提示词”时，只输出完整提示词，不调用图片生成。
- 如果用户没有给具体主题，先基于上下文推断；确实无法推断时，再问一个简短问题。

## 避免项

- 不要复刻预览图或参考图的完整文字、Logo、水印、账号名、真实品牌资产或专有角色。
- 不要把用户长文整段塞进画面；先压缩成短标题、短标签和清楚的关系。
- 不要让装饰、图片、卡片、箭头或背景纹理压住文字。
- 不要为了风格一致而牺牲当前内容的清晰表达。
- 不要做成暗黑霓虹、复杂芯片照片、赛博海报、密集大屏或真实设备广告。
