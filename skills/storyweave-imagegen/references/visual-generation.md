# 生成时预防视觉 AI slop

本规则用于 StoryWeave 的内容规划、HTML 构图、Imagegen 提示词与视觉复核。制作或修改演示前必读。它改编自 Damir Sokolovsky（[@heydamir](https://x.com/heydamir)）的视觉版 [unslop](https://github.com/heydamir/unslop/tree/1d13095e4bef6ad6c74f1dd828d84c4ba309a4dc)，固定来源为 `1d13095e4bef6ad6c74f1dd828d84c4ba309a4dc`，按 [CC BY 4.0](https://github.com/heydamir/unslop/blob/1d13095e4bef6ad6c74f1dd828d84c4ba309a4dc/LICENSE)保留署名。分发包里的同名参考由打包脚本同步。

unslop 先找实际问题和产品自己的视觉方向，再按间距、颜色、图标、文案、字体、布局、细节、素材和动效逐层处理。局部问题优先局部修整，已有清楚设计不为制造变化而重做。StoryWeave 保留演示文稿的批准内容、主题媒介与固定舞台，不机械移植网页导航尺寸、移动重排、标点或字体禁令。

## 构图之前

在项目工作记录 `visual-intent.json` 中写清以下问题。使用已有资料与授权，不增加默认确认步骤；该记录属于设计输入，不是页面可见文字。

| 问题 | 具体回答 |
| --- | --- |
| 内容与观众 | 给谁看，要理解哪个批准主张，观看距离与阅读模式是什么 |
| 视觉方向 | 哪种字体、媒介和材质适合此内容，描述实际特征，避免只写现代、高级、极简 |
| 表达形式 | 比较轴、流程、数据、关系图或观点承担什么信息，观众从哪里开始读 |
| 素材用途 | 若需要图片，用一句话说明对象如何解释主张；不需要图片时允许纯文字或图解 |
| 保留与修改 | 更新时指出实际问题、位置和最小修复，保留清楚的关系与构图 |

内容决定表现对象，主题提供表达语言。科技主题不自动需要机器人或电路，纸面主题不自动需要折纸物体。不能去掉一种装饰后再加入另一种流行装饰。换掉项目名称后仍完全适用的图像或口号，需要重新检查与主张的联系。

没有明显问题时保留原版。断词先调整词组和容量，箭头贴字先修轨道，不顺带改变整页方向、配色与媒介。两个主题可以共用易读的构图，样式差异由字体、色彩、线条和材质承担。

## 生成中的判断

| 信息任务 | 视觉选择 | 需要排除的问题 |
| --- | --- | --- |
| 观点 | 批准主张成为第一焦点，正文或相关图像提供支持 | 通用大物体、无关背景、空泛标题取代主张 |
| 比较 | 相同的行列轴、对齐和中性权重 | 任意高亮末列，让观众误认某项获胜 |
| 指标 | 数值与各自单位、标签和来源紧邻 | 无数据的趋势线、进度条、增长箭头和虚构 KPI |
| 流程或系统 | 步骤、方向、分支和汇合本身成为画面 | 端点虽正确但路线过平、绕远、交叉、假分组或假反馈边 |
| 图片 | 能解释具体内容的对象和视角，给文字留出安静区域 | 仅表达气氛的球体、光晕、机器人、拼贴或占位面板 |

先组织真实信息，再分配重点。辅助表面、边框和图标保持安静，颜色和细节集中于证据或关系。选定媒介确实需要丰富色彩、印刷纹理或场景时可以保留，但须说明用途；不能把所有页面统一洗成灰色作为去 slop 的替代方案。

以下是复核信号，不是与语义无关的禁用词清单：每块内容都强调、每张卡都有图标、无意义徽章、浮动物体、发光边框、渐变大字、随机字体与间距、重复的等宽卡片、过重标题、无用的循环动效。发现时指出位置及影响，删除或减弱没有职责的元素。内容确实讨论的对象、用户指定的视觉语言与必要品牌元素优先保留。

留白表示分组，组内距离小于组间距离。数字按用途对齐，标签邻近对应对象。不能以小字硬塞，也不能把关联节点分得很散后解释为高级感。页面先在静态、没有装饰效果时读得清楚，再考虑有解释作用的动效。

所有可见文字仍来自批准内容。资料、参考页和主题示例不能提供本项目的新数字、姓名、Logo、图注或产品界面；看起来真实的假数据仍是假数据。批准文案需要修改时回到内容确认，不为了去 AI 味擅改。

## Imagegen 实际输入

私有计划保存 `visual_policy` 与逐页 `visual_intent`。后者表达内容职责，`review_status: required` 不表示已通过视觉检查。实际提示词按内容类型编入比较、流程、指标、关系或观点的要求，并允许省略主题中的无关道具。策略进入计划与任务指纹，旧计划先 replan，旧任务结果不能冒用新任务的通过状态。

需要场景时，先明确主体、动作或关系，再写环境、媒介、光线与颜色、主体位置和文字空区。少量准确决定优先于高端、惊艳、电影级等形容词堆叠。无需场景的技术页直接画批准的图解。主题连续性保留相关色彩、字体或材质，不把同一道具放到每页。

## 生成后

实际查看每页与整套。判断主张是否得到支持、重点与阅读顺序是否清楚、关系是否易辨、对齐和比例是否合理、素材是否属于当前内容，再看整套是否连贯。更新时以相同内容、视口和尺度比较前后，记录改善、持平、退步或不确定。任何维度退步不能由其他页改善抵消，不确定保持未复核。

计划和提示词验证只证明约束存在，不自动识别画面是否有 AI slop。技术 QA、review 标记或漂亮缩略图不能代替逐页看图。HTML 或 PNG 变化后重新检查实际产物，只重做有问题的页面。
