# 扩充演讲与分享稿的整页视觉参考

## 背景与问题

Imagegen 的参考入口需要帮助选择整套演示的视觉语言。独立器官、机械物体和微缩模型无法证明某种风格适合承载演讲内容，普通 HTML 模板预览也不应重复归入 Imagegen。

## 实现范围

将主参考入口改为完整内容页，按标题、主张、分组和讲解关系筛选。8 组样张覆盖技术蓝图、暖色电路、粉笔讲解、手绘知识、深色系统、玻璃产品、水墨方法与黏土流程。每组保留固定来源版本、原图、样式或样张提示词、实际页面职责与适用限制。

34 组有 HTML 源文件的模板保留在 HTML 参考侧。原有 9 组独立插画保留为研究存档。目录和静态画廊由单一 JSON 生成，原图从来源加载。全局 Skill 仅增量同步参考资源和入口。

## 验收

- Skill 主入口和主题文档均链接演讲与分享稿参考。
- 8 组实际内容页具有标题与内容结构，原图和提示词来源可追溯。
- 目录标明已观察的页面职责，不以一张样图宣称整套主题覆盖。
- 静态画廊与权威目录一致，分类、搜索、空状态和来源链接可检查。
- 全局脚本、六套主题和工作流的哈希不变。
- 原图不进入四个 Skill 包，不新增图片 API、服务或运行依赖。
